# Rule: Spec Quality Gate (stub)

> Detalhe completo movido para a skill [spec-execution](../skills/spec-execution/SKILL.md) — carregada on-demand em execução/closeout de spec. Stub preserva path + invariante.

**Invariante:** Build passing não basta; uma spec só pode ser `BUILD_VALIDATED` com evidência de que os critérios centrais foram implementados, auditados e documentados; taxonomia de status canônica vive na skill; nada vai para `implementados/` sem evidência do nível exigido.
