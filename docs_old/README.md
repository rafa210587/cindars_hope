## Uso obrigatorio

Ao criar ou revisar uma nova spec em `docs/specs/`, validar contra:

1. `PROJECT_LOG.md`.
2. `docs_old/MANIFEST.md`.
3. `AGENTS.md` / `CLAUDE.md`.
4. `docs_old/SPEC_EVOLUTION_POLICY_v1.0.md`.
5. Evidencia real no codigo em `Assets/_Game/Scripts/**`.

## Regra

`docs_old/` e somente leitura historica.
