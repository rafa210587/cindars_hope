# Unity Asset Generation

Use this skill when a spec requires ScriptableObject, scene, prefab, or registry assets generated by Unity editor tools.

## Before Running

1. Identify exact menu or `-executeMethod` target.
2. Verify the method is `public static`.
3. Verify the output folders.
4. Check whether Unity is already open for the same project.
5. Prefer sequential Unity executions; do not run multiple batchmode generators in parallel for the same project.

## Standard Command

```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.4.7f1\Editor\Unity.exe" `
  -batchmode `
  -quit `
  -projectPath . `
  -executeMethod <Namespace.Type.Method> `
  -logFile Logs\<spec>_<generator>.log
```

## After Each Generator

Inspect the log:

```powershell
Select-String -Path Logs\<spec>_<generator>.log `
  -Pattern "error CS|Exception|Fatal|created|updated|complete|PASSED|FAILED" `
  -CaseSensitive:$false
```

Count output assets:

```powershell
Get-ChildItem -Path "<asset-folder>" -Filter "*.asset" -Recurse |
  Measure-Object |
  Select-Object -ExpandProperty Count
```

## Required Documentation

Record in `docs/validation/<SPEC>_<date>.md`:

- Generator method attempted.
- Log file.
- Exit code.
- Assets expected.
- Assets found.
- Divergence from requested menu name, if any.
- Whether generation was blocked by Unity lock, license, timeout, sandbox, or approval.

## Failure Handling

If Unity says another instance is open:

```text
Unity asset generation: BLOCKED
Reason: another Unity instance is running with this project open
Command attempted: <command>
Residual risk: generated assets were not refreshed locally
```

If no `error CS` exists but package/test assemblies are "not valid", treat as tooling noise unless the generator did not run.

## Rules

- Do not run Unity generators in parallel for the same project.
- Do not treat a missing menu name as failure if an equivalent editor method exists; document the divergence.
- Do not manually fake generated assets unless the spec explicitly allows it.
- Do not mark asset generation complete without log and asset-count evidence.
