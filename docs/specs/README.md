# Specs - Cindar's Hope

## Estrutura

- `docs/specs/implementados/`: specs normalizadas de capacidades ja existentes no repo.
- `docs/specs/a_implementar/`: specs futuras aprovadas ou em preparacao.
- `docs_old/`: historico integral da documentacao anterior.
- `docs/refinements/`: mapas de refinamentos implementados e futuros.

## Regras

- Toda spec implementada deve ter prefixo `spec_`.
- Specs antigas continuam preservadas em `docs_old/`.
- Uma spec implementada deve apontar evidencias reais de codigo, status historico e pendencias.
- Implementacoes parciais devem distinguir MVP/debug de comportamento final pretendido.
