# Features futuras

Esta pasta contem specs futuras/future mapped que nao devem ser executadas por automacoes de implementacao.

## Regra

Specs nesta pasta sao fora do escopo executavel atual.

Para executar qualquer uma delas, e necessario:
1. decisao humana explicita;
2. mover a spec de volta para `.specs/a_implementar/`;
3. remover marcacoes de `future`, `future mapped` ou `_future_`;
4. atualizar `SPEC_REGISTRY_TO_IMPLEMENT.md`;
5. criar ou atualizar plano de execucao da wave correspondente.
